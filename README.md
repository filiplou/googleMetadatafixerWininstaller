# googleMetadatafixerWininstaller
ready to go Win11 installer for https://github.com/ihimanshurawat/google-photos-metadata-fixer project

Google Photos Metadata Fixer for Windows
=========================================

Installation
------------
1. Double-click "Google Photos Metadata Fixer_1.0.0_x64_en-US.msi".
2. Follow the installer prompts.
3. Launch the app from the Start menu or desktop shortcut.

What it does
------------
This app restores dates, locations, captions, and other metadata from Google
Photos Takeout JSON files into the matching photo and video files.

Privacy
-------
Processing runs locally on your computer. Your photos are not uploaded.

Troubleshooting
---------------
If Windows SmartScreen appears, verify that you downloaded the installer from
a trusted source and choose "More info" followed by "Run anyway" only if you
trust the file.

The app requires 64-bit Windows 10 or later.
